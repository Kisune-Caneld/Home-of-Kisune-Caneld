# Agent Guidelines for Home-of-Kisune-Caneld backend

Developed using Django with the Django REST Framework library. 
Although the app operates in a nearly serverless manner, Django is still required to handle requests such as chatbots, reasoning, etc. 

Please read pyproject.toml and the core/ directory for a better understanding of the structure. 

Please note that the database used is PostgreSQL 18 with pgvector integrated.
